# منجز — Monjiz

فريمبلانس ماركت بليس مصري: محترفون موثقون ينجزون أعمال العملاء — تصميم، تطوير مواقع، تسويق رقمي، ودعم أعمال.

An Egyptian freelancing marketplace: verified professionals getting clients' work done — design, web development, digital marketing & business support.

## Pages
- `index.html` — landing page
- `freelancers.html` — browse freelancers per niche (`?niche=design|web|marketing|business`)
- `signup/freelancer.html` — freelancer sign-up
- `signup/client.html` — client sign-up

## Tech
Static HTML/CSS/JS. Arabic ⇄ English (via `js/i18n.js`).
Registrations are currently stored in the browser's `localStorage` (per-device).
